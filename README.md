# 特斯拉省钱小票

在车主自己的电脑上授权 Tesla、从当天开始记录新行程，并把数据翻译成可核验、可分享的人民币账单。项目不运营公共服务器，原始车辆数据不离开车主设备。

## 当前产品边界

- 主结论：所选周期的 TeslaMate 行程功率积分耗电、用户综合电价换算的行程电费，以及相对指定燃油车的估算差额。
- 飞书对比名称：日产轩逸、宝马5系、路虎卫士、保时捷911、兰博基尼超跑。后台分别锁定十五代轩逸、BMW 530Li、卫士 110 P400、911 GT3 和 Aventador S Roadster 作为计算版本。对比金额必须显示油耗来源、油价来源和口径日期。
- 1.0 输入：TeslaMate 从授权之后在本机记录的新行程，以及用户在飞书确认过的充电账单截图。车辆与路线数据不靠截图。
- 1.0 输出：带真实单程 GPS 轨迹和粗粒度起终点道路的“行程小结”、合并本月行程统计的车辆概览、周结/月结和五档油车预计油费对比。
- 路线人民币热力图保留为实验模块；它同样只分析授权后的新行程，不能回填授权前路线。
- 成本边界：1.0 只计算能源账，不混入购车、保险、折旧、停车和时间成本。
- 服务边界：不接收 Tesla 账号、密码或 Token，不为用户托管车辆数据，也不提供共享后端。

## 1.0 体验

1. 用户在自己电脑上安装项目与 TeslaMate。
2. 用 Tesla Auth 在本机 Tesla 登录页完成授权，将 Access Token 和 Refresh Token 粘贴到本机 TeslaMate；凭证不经过项目方。
3. TeslaMate 从此刻开始将新行程、位置和充电数据写入本机 PostgreSQL。
4. 自研服务只读数据库；充电账单优先由 Apple Vision 在本机识别，K3 仅在本地结果缺少关键字段时作为可选兜底。电量换算和费用校验由确定性代码完成；经用户确认后写入本地账本，不回写 TeslaMate。
5. 飞书菜单仅保留“上次行程 / 车辆概览 / 本周小结 / 本月小结”。充电账单无需先点按钮，直接发送图片就会识别并返回待确认卡。

路线轨迹只出现在“行程小结”，不在周结/月结叠加多次路线。轨迹只使用已关联完整行程的 GPS 点，不使用停车 GPS 漂移；中国境内展示时将 WGS-84 转为 GCJ-02 后叠加高德路网底图。起终道路来自 TeslaMate 地址表，中途道路名在未接入地图匹配前不做猜测。

单次行程轨迹按功率做平滑和分段，再以本次行程内部分位标记为绿（低耗）、橙（中耗）、红（高耗）。这是同一趟行程的相对强弱，不是跨车型、跨路线的绝对能效评分。

行程耗电优先对 TeslaMate `positions.power` 按采样时间做梯形积分，将回收功率计为负值，且忽略超过 10 秒的采样缺口。周/月小结顶部只高亮累计行程、累计耗电和行程电费；油车对比使用飞书 Card 2.0 原生横向金额柱状图，不以升数作为主表达。

> 授权本身不会累积数据。TeslaMate、PostgreSQL 和 M5 必须已经运行，且 M5 在开车时保持唤醒和联网。离线期间错过的行程无法补录。

Owner API Token 不是可验证的细粒度“只读 Token”，因此对外不宣称“只读授权”。本项目的保障是：自研代码只读 TeslaMate PostgreSQL，不发送任何车辆命令。

## 目录

```text
docs/research/   调研、证据和外部接口结论
docs/product/    产品定义、交互和内容方案
src/             分析与生成代码
infra/           可选的 TeslaMate/路线实验配置
infra/feishu/    专属飞书机器人权限、事件与运行说明
data/raw/        原始车辆数据，仅本地保存，不入库
data/processed/  脱敏后的处理中间数据，不入库
output/          可分享的图片、卡片和报告
```

## M5 → M1 迁移

代码使用私有 GitHub 仓库备份；历史数据通过 iCloud Desktop 传输一次性 AES-256 加密包。不要把 PostgreSQL volume、`.env`、原始 GPS 或充电账单目录直接放入 iCloud 同步。

完整操作与回滚见 `docs/engineering/260825_M5迁移M1_方案与操作.md`。

## 当前阶段

1. 在 M5 上部署 TeslaMate 官方项目的 4.1.1 镜像与 PostgreSQL。
2. 用 Tesla Auth 0.15.0 验证中国账号 Token 生成和 TeslaMate 连接。
3. M5 通过项目 LaunchAgent 常驻并保持唤醒；跑一次真实短行程，确认 `drives` / `positions` 已入库。
4. 累积至少两次符合 TeslaMate 条件的充电会话后，再验证行程能耗估算和人民币小票。
5. 只读接入 TeslaMate PostgreSQL，不自研车辆轮询器。
