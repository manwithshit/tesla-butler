# 开源采集方案选型

日期：2026-08-23

## 结论

当前 M5 原型选择 **TeslaMate 4.1.1 + Tesla Auth 0.15.0 + PostgreSQL**。它可以在车主本机完成 Tesla 登录和 Token 生成，并从启用后自动记录新行程。

不直接用 Tesla 官方 `fleet-telemetry` 做 1.0，也不用截图。官方开源组件是底层基础设施，不是完整的车主数据账本。

## “Tesla 的开源项目”到底指什么

### Tesla 官方

#### 1. Fleet Telemetry

- 仓库：https://github.com/teslamotors/fleet-telemetry
- 作用：接收车辆通过 mTLS WebSocket 主动推送的实时遥测数据。
- 它是 Go 编写的参考服务端，可将数据送入 Kafka、Kinesis、MQTT、Redis 等后端。
- 它不提供车主行程账本、数据库 schema、能耗计算或业务仪表盘。
- 官方文档要求遥测接收器在公开互联网运行，并配置开发者应用、HTTPS 域名、公钥、虚拟钥匙和车辆遥测配置。

#### 2. Vehicle Command SDK

- 仓库：https://github.com/teslamotors/vehicle-command
- 作用：提供车辆端到端命令认证的 Go SDK、CLI 和 HTTP proxy。
- 它包含密钥生成、命令发送和 Token 保存工具，但 `tesla-auth-token` 不负责获取 OAuth Token。
- 它不是数据记录器，而且本项目不需要车辆控制命令。

#### 3. Fleet API

- Fleet API 是 Tesla 托管的官方 API，不是一个可下载运行的开源项目。
- 官方 OAuth 需要开发者应用、公开域名和回调地址；若启用命令/遥测，还需要车辆虚拟钥匙配对。
- 中国区官方 `charging_history` 目前仍标注“暂未开放，即将推出”，不解决历史导入。

## 为什么选 TeslaMate

1. 它已经解决最难且最容易出错的部分：车辆休眠、轮询/流式数据、行程分段、GPS 点、充电会话和本地持久化。
2. 它的 PostgreSQL 数据库可供我们只读分析，无需重写 Tesla 采集器。
3. 它已有 Docker、Grafana 和 MQTT，后续可直接触发行程结束事件。
4. 它默认使用非官方 Owner API；TeslaMate 官方文档明确表示，个人账号当前仍可使用，且数据粒度高于当前 Fleet API 路径。

## 授权的真实产品体验

TeslaMate 不内置初始 Token 生成。推荐搭配 Tesla Auth：

1. 用户在自己的 M5 上启动 Tesla Auth。
2. Tesla Auth 打开 Tesla 原生登录页，支持 MFA 和 Captcha。
3. 它在本机展示 Access Token 和 Refresh Token。
4. 用户将两个 Token 粘贴到本机 TeslaMate。

Tesla Auth 源码包含 `https://auth.tesla.cn/oauth2/v3/token`，并根据授权回调的 issuer 切换到中国 Token 端点。这是“中国账号可行”的源码证据，但不等于已在当前用户账号和 M5 上验证成功。

## 已知限制

1. **不能补历史**：TeslaMate 官方 FAQ 明确说明，Tesla API 不提供历史 drives / charges，采集停止期间的数据无法恢复。
2. **授权不等于采集**：TeslaMate 和数据库必须已运行。
3. **M5 必须常醒**：TeslaMate 官方安装要求一台 always-on 的主机。M5 睡眠时可能漏记行程。
4. **行程耗电是估算值**：Tesla API 不直接返回单次行程耗电；TeslaMate 需基于充电数据估算，至少两次符合条件的充电会话后才出现首次估算。
5. **Owner API 可能变更**：这是 TeslaMate 当前的个人用户默认路径，但不是 Tesla 对第三方产品承诺的长期公开 API。
6. **中国账号仍需实车验证**：TeslaMate 维护者表示代码已支持中国账号，但测试覆盖程度不确定；若自动识别失败，需指定中国 Owner API / streaming 端点。
7. **不是细粒度只读授权**：Owner API Token 不能按 Fleet API scope 模型认定为只读 Token。本项目只能保证自研服务只读数据库、不发送车辆命令。

## 竞品对本项目的直接影响

`wjsall/teslamate-chinese-dashboards` 已经提供：

- TeslaMate 中文 Grafana 仪表盘；
- 高德地图和 WGS-84 → GCJ-02 坐标纠偏；
- 分时电价；
- 省钱分析和燃油车对比；
- 年度报告、行车/停车耗电、驾驶评分等。

因此本项目不能再把“给 TeslaMate 加一个省钱仪表盘”当成独特产品。差异化收敛为：

1. 默认同屏对比轩逸、高尔夫、宝马 5 系、911 和兰博基尼五个具体锚点；
2. 每趟行程自动生成一张「省钱小票」，而不是只有 Grafana 大看板；
3. 周/月定时送到用户自己的飞书；
4. 把“这趟路花了多少，换成五台油车分别多少”做成可分享的内容产物。

## 下一步

1. 先完成 M5 上 Docker Desktop 的管理员组件安装。
2. 使用 TeslaMate 官方项目的 4.1.1 镜像搭建本地栈，不直接执行第三方网络一键脚本。
3. 下载 Tesla Auth 0.15.0 Apple Silicon 签名发布包并校验 SHA-256。
4. 由用户本人完成 Tesla 登录；我不读取、不记录 Token。
5. 保持 M5 唤醒，用一次短行程验收端到端采集。
