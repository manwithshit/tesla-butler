# 飞书卡片能力与车型对比视觉方案

> 调研日期：2026-08-23  
> 范围：飞书 Card 2.0、VChart、特斯拉小管家的飞书表达。

## 结论

1. 旧的文字字符进度条可以淘汰。Card 2.0 已支持原生 `chart`，内部使用 VChart；VChart 官方支持 `linearProgress` 和 `circularProgress`。
2. 但当前 Card 2.0 组件清单里没有独立的 `progress` 组件。`linearProgress` 能否被飞书 PC 和移动端稳定渲染，必须用真实卡片验证，不能只根据 VChart 文档宣称已支持。
3. 本项目最适合的不是“一张全由飞书组件堆出来的卡”，而是“可保存/分享的主视觉图 + 飞书原生数据和交互”的混合卡。
4. 车型不应五台等权平铺。第一焦点只展示“Tesla vs 轩逸”，高尔夫和宝马 5 系进入日常对比图，911 和兰博基尼放在“如果开性能车”的娱乐区。

## 已验证能力

### Card 2.0 可以直接承载

- 数值指标：`column_set + markdown`，适合“本月电费 / 里程 / 比轩逸节省”。
- 图表：`chart`，`chart_spec` 使用纯 JSON 的 VChart spec；已明确列出折线、面积、柱/条形、饼/环、散点和词云。
- 图片：`img` 或 `img_combination`，需先上传获得 `img_key`。单图不超过 10 MB，尺寸不超过 1500×3000 px。
- 表格：`table`，可展示车型、油耗、油价、估算费用和数据日期；但移动端不宜把它放在第一屏。
- 折叠区：`collapsible_panel`，适合收纳油耗、油价、电价、计算公式和来源。
- 交互：按钮、下拉、输入框、日期等可产生 `card.action.trigger`，并可在用户操作后更新卡片。
- 转发：`config.enable_forward` 可控制是否允许转发。

### 尚未验证

- 飞书卡片的 `chart` 虽然声明使用标准 VChart spec，但其文档没有把 `linearProgress` 列入常用类型。
- 因此只能确认“技术上有路径”，不能确认“飞书各端已稳定支持”。
- 卡片文档明确提醒：移动端不支持部分 VChart 属性，因此最终必须在真实 iPhone 飞书上做视觉验收。

## 进度条怎么改

| 场景 | 推荐表达 | 不推荐 |
| --- | --- | --- |
| 数据冷启动，例如“累积 7/30 天” | 大数字 `7 天` + VChart `linearProgress` | `████░░` 文字字符 |
| 本月目标，例如“已统计 68%” | 线性进度图；兼容性失败则用单系列水平条形图 | 环图同时放多个指标 |
| 车型费用对比 | 水平条形图，直接比较人民币 | 进度条：没有统一目标，语义错误 |
| 安装/授权步骤 | 步骤标签 + 当前状态 + 一个主按钮 | 用百分比伪造精确进度 |

## 推荐的飞书卡片结构

### 1.0 主卡：月度省钱总账

```text
┌ 8 月特斯拉小管家─────────┐
│ [可保存主视觉图]                          │
│ 本月电费 ¥128.40                             │
│ 同样 812 km，比轩逸少花 ¥367.20            │
├ 里程 812 km │ 度数 103 kWh │ 每公里 ¥0.16 │
├ [日常车对比：水平条形图]              │
│ Tesla / 轩逸 / 高尔夫 / 宝马 5 系              │
├ [如果开性能车]                           │
│ 911 ¥……，兰博基尼 ¥……（数字卡，非长条图）    │
├ [本月哪几天跑得最贵：日历热力图]        │
├ [展开计算口径]   [电价不准，补充账单]       │
└──────────────────────────────┘
```

### 为什么采用混合卡

- **主视觉图**：承担品牌感、车型剪影、日历热力图和社交分享。用户可以直接保存或截取第一屏。
- **原生卡片组件**：承担真实数据、自适应、折叠口径和交互按钮。
- 纯飞书组件能做得干净，但很难做出小红书封面级别的“一眼想分享”。
- 纯图片虽好看，但无法在卡片内改电价、查口径或更新状态。

## 车型展示规则

### 第一焦点

```text
同样跑 812 km
Tesla 电费 ¥128
轩逸理论油费 ¥496
本月少花 ¥368
```

轩逸是默认锚点，因为“比一台常见家用油车少花多少”比“相当于多少 kWh”更容易被理解。

### 第二层：日常车对比

- Tesla：唯一高亮色。
- 轩逸、高尔夫、宝马 5 系：同一中性灰色系，不每台车使用品牌色。
- 条形末端直接标人民币金额；默认按费用从低到高排序。
- 不用饼图、雷达图或各品牌 Logo 墙。

### 第三层：性能车娱乐区

- 911 和兰博基尼不进入同一条形图，避免极端值压缩日常车的差异。
- 各用一张紧凑数字卡：“如果是 911，本月约 ¥X”、“如果是兰博基尼，约为 Tesla 的 X 倍”。
- 它们承担戏剧性和转发点，不承担主结论。

## 视觉约束

- 第一屏只能有一个最强数字：“比轩逸省 ¥X”或“本月只花 ¥X”，二选一。
- 整卡主色系不超过 3 类；Tesla 与油车的区别用高亮色/灰色，不用五个品牌色。
- 视觉块保持 2–5 个；公式和来源默认折叠。
- 主卡默认宽度不超过 600 px，所有图表必须在飞书 iPhone 端验收。
- 公开分享素材不必使用车企 Logo；优先用车型名和自制剪影，避免整张变成品牌贴纸墙。

## 1.0 不建议做

- 不做五台油车平均分割的品牌 Logo 墙。
- 不做一张超长明细表当首屏。
- 不在一张图里同时表达电费、油费、碳排、时间、能耗和路线。
- 不使用彩虹图表；不为每台车分配一种鲜艳色。
- 不把 911/兰博基尼当成精确购车决策建议；它们只是能源费用对比锚点。
