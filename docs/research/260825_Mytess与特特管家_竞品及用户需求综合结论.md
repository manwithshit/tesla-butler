# Mytess、特特管家与小红书用户需求：综合结论

> 日期：2026-08-25  
> 用途：决定字段、视觉与驾驶建议的后续优化方向。  
> 边界：除“删除所在区域、合并起止时间”外，本报告中的建议本轮均未实施。

## 结论

当前产品不应和竞品比“谁的数据更多”，而应把差异固定为：**真实账单进入飞书后，主动生成一张能立刻看懂的钱、路线和可信解释小票。**

驾驶建议不要继续沿用“红色高耗段集中，请少急加速”这种泛化模板。推荐改成条件触发的“行程洞察”：只有道路匹配、相对基线和影响因素足够可靠时才出现；证据不足时只指出异常路段，不评价驾驶习惯。

视觉和字段不再扩张。单程维持“地图 + 4 个主指标 + 时间/路线 + 1 条洞察”；周/月维持“钱的结论 + 里程/电耗证据 + 五台油车同里程预计费用”。

## 两条证据如何互相印证

| 问题 | App Store / 公开资料 | 小红书评论证据 | 结论 |
|---|---|---|---|
| 用户是否需要更多字段 | 特特管家已有 `3×3` 行程指标、曲线和大量车辆字段 | 最强诉求是“数值是否正常、为什么高”，不是继续加字段 | 不做字段墙 |
| 驾驶建议怎么写 | Mytess 仅在有模式时出洞察；特特公开示例偏指标拼接和总分 | 用户质疑黑盒评分、误判和扣分标准 | 不做总分；给事件证据和不确定性 |
| 地图有什么价值 | 两款均已有地图/轨迹，彩色路线也非独占 | 用户要中文道路、起终点语义；纯折线更多是“好玩” | 地图必须承担道路叙事，不只是装饰 |
| 周/月报是否差异化 | Mytess 已有周/月、费用、节省金额和同路线比较 | 主动行程通知只有少量直接诉求 | 周/月本身不是卖点；飞书自动送达和人民币表达才是 |
| 什么阻止用户采用 | 评论涉及付费层级、隐私和稳定性 | 安装/连接/兼容命中 62 条，是本轮最大需求簇 | “是否已连接并开始积累”属于核心产品信息 |

## 推荐的单程卡信息结构

1. **Hero：本次预计花费**，一句话先回答“这趟花了多少钱”。
2. **2×2 指标：**估算花费、估算电耗、行驶里程、行驶时长。
3. **地图：**起点、终点、能耗颜色图例和最高异常段。
4. **路线信息：**道路 A → 道路 B；起止时间合并一行。
5. **行程洞察：**最多一条；没有可靠证据就不显示。

默认不展示：所在区域、最高速度、最大功率、动能回收、技术口径、坐标转换和驾驶总分。

## 驾驶建议的推荐规则

### 名称

将“本次驾驶建议”改为“本次行程洞察”。理由：当前数据通常只能解释一次异常，不能稳定评价驾驶者。

### 触发门槛

同时满足以下条件才输出道路级动作建议：

1. 道路匹配可靠，能识别方向或相邻道路关系。
2. 该路段单位里程能耗明显偏离本次平均或同路线个人基线。
3. 至少有一种可核验因素：走停/速度变化、坡度、低温、空调或能量回收受限。
4. 建议动作与证据直接相关，不推断“用户开得激进”，不建议开启自动驾驶。

不满足第 3 条时，只报告异常段和不确定性；不满足前两条时，整块隐藏。

### 固定文案结构

`道路/时间锚点 → 观察事实 → 原因与不确定性 → 下一次一个动作`

推荐示例：

> 18:42–18:45，从 A 路转入 B 路后的 1.2 km，本段单位能耗比本次平均高 28%。这段同时出现低速走停，暂不能区分拥堵和加速的影响。下次经过时保持平缓跟车；积累 3 次同路线后再判断是否稳定偏高。

证据不足示例：

> A 路至 B 路是本次耗电最高的一段；当前无法排除坡度、空调和拥堵影响，本次只标记路段，不评价驾驶习惯。

禁止使用：

- “红色高消耗段集中，请降低电门。”
- “本次驾驶 72 分。”
- “这里耗电高，建议开启自动驾驶。”

## 周/月卡的推荐表达

### 本周

- 第一层：本周实际/估算花费。
- 第二层：累计里程、累计电耗、行驶时长。
- 第三层：五台油车跑同样距离的预计油费，直接显示金额。
- 第四层：一句结论，例如“同样跑 184 km，预计比宝马 5 系少花 ¥X”。

### 本月

- 只保留一个可传播 Hero 结论，不画整月全部轨迹。
- 地图只选“本月最贵的一程”或“最常走路线”之一。
- 环比只在统计周期和费用口径完整时出现。
- 所有金额标记为实际、估算或未知。

## 视觉建议

1. 保留当前地图主视觉和 2×2 指标，不复制特特管家的 `3×3` 字段墙。
2. 地图颜色一次只表达一个维度，当前优先表达单位里程能耗；图例写成“较低 / 接近本次平均 / 较高”。
3. 暗黑模式避免纯白高光、浅灰小字和透明玻璃效果；金额是唯一视觉主角。
4. 分享图默认模糊家庭、公司和精确起终点；地图可看，地点不可反推。
5. 3D 车辆、徽章、排行榜、TOP 数据不进入 1.0。

## 优先级

### P0

1. 将产品定位锁定为“飞书里自动到账的真实省钱小票”，不再以地图、周月报、油电对比本身宣称独有。
2. 驾驶建议改为有证据才触发的行程洞察；不做黑箱总分。
3. 新增运行信任信息：TeslaMate 是否连接、数据开始积累时间、最近同步时间、暂无数据的原因。
4. 费用始终区分实际、估算和未知。

### P1

1. 道路级洞察加入时间、方向、相对基线和不确定性。
2. 月报加入一个 Hero 结论和一条代表性路线，不叠整月轨迹。
3. 飞书白天/暗黑模式分别做真实可读性验收。

### P2

1. 积累足够数据后再做同路线历史比较，并控制天气、拥堵和空调等变量。
2. 先按天汇总多段短途，再下钻单次。

## 本轮证据和边界

- App Store/公开资料：2 个中国区产品页、2 个 Apple Lookup 接口、65 条公开评论、20 张官方截图及官方文档/隐私页。
- 小红书：8 个关键词，120 条次、108 条去重笔记、34 篇详情、365 条评论，筛出 259 条相关评论；抓取失败 0。
- 强证据：绝对能耗缺少参照；安装、连接和数据积累状态不清。
- 中等证据：地图需要道路语义；隐私、安全、费用口径影响采用。
- 弱证据：每程主动推送、暗黑模式、历史数据和道路级建议。
- 未验证：两款竞品算法准确率；道路级建议能否改变驾驶行为；五台油车金额对比的长期留存价值。
