# 视频承诺与产品边界

日期：2026-08-23

## 已验证事实

1. Tesla App 已经提供“燃油费节省金额”。官方口径为：可比较燃油车的燃油当量成本减去充电总支出。
2. Tesla App 还提供统计周期内总充电量、总花费，以及家庭、公司、其他、超级充电等分类。
3. Tesla 车机能显示当前行程、自上次充电以来的距离、时长、总能耗和平均能耗。
4. 官方 Fleet Telemetry 能提供实时车辆、里程和能耗信号，但需要车辆授权后持续传输到在线的接收端。
5. TeslaMate 无法补回停止记录期间或安装之前的历史行程。

## 口播中需要修正的四句话

| 原表达 | 问题 | 推荐口径 |
|---|---|---|
| “省了多少电” | Tesla 消耗的是电，比较的是油费/能源费 | “到底省了多少油费”或“能源费” |
| “官网/App 应该没有这个数据” | App 已有“燃油费节省金额” | “App 有一个总数，但没有告诉我具体拿哪台油车比” |
| “授权 App 数据就能拿到每一车历史” | 官方没有可回填的完整历史行程接口 | “在自己电脑上授权，从今天开始记录新行程” |
| “工具会推每一次、每周、每月” | 产出过多，且逐程推送容易骚扰 | “本地记录每一程，每月推送一张总账” |

## 视频中可以承诺

- 用户在自己电脑上完成 Tesla 授权；
- 从授权且采集器开始运行之后记录新行程；
- 与轩逸、高尔夫、宝马 5 系、911、兰博基尼等具体车型比较；
- 公开公式、油耗、油价、电价和日期；
- 用户可选开启本地持续记录；
- 用户可把月报连接到自己的飞书；
- 数据由用户自己保存在本机，不经过项目方服务器。

## 视频中暂时不能承诺

- 授权后自动补回所有历史行程；
- 电脑休眠或采集器离线时仍能完整记录；
- 单次行程电费等于真实电费账单；
- 已经实现稳定的路线热力图；
- “授权一次、什么都不用安装”即可持续生成月报；
- “授权完成后即使 M5 睡眠也会自动积累”。

这些能力必须在真实车辆连续运行验证后才能进入口播成片。

## 推荐展示顺序

1. 第一屏直接放真实结果：本月 Tesla 电费与五台油车费用差。
2. 回到问题：Tesla App 虽有节省金额，但比较对象不具体。
3. 用一个短镜头展示“在自己电脑上完成 Tesla 授权”，不展示 Token。
4. 展示几天后真实积累出来的行程小票、周结和热力图。
5. 结尾展示飞书收到的周/月报，而不是技术安装过程。
