# 产品方向：特斯拉小玩家

## 定位

不是证明电车一定省钱，而是把一个真实周期的能源账算清楚，并让任何 Tesla 车主都能在本地复刻。

## 1.0 产品结构

1.0 只保留一条路径：**本地授权后开始持续记录新数据**。

不接受截图、OCR 或手工抄录作为产品输入。用户首次安装后会经历一个数据冷启动期，这是用授权丝滑度换取的明确取舍。

## 核心产物

只保留一个对外核心产物：**月度省钱总账卡**。

一张卡同时包含：

1. 周/月/年累计里程、总充电量、实际/估算电费、平均每公里电费；
2. 与五台指定燃油车的理论油费和差额；
3. 按日期或充电类型着色的能耗/花费热力图；
4. 油耗、油价、电价、统计周期和公式口径。

本地会保存单次行程明细，但默认不逐程推送。用户每个月收到一张飞书总账即可。

不把驾驶建议、地图 API、路线优化放入 1.0。

## 用户路径

### 第一次使用

1. 在本机安装项目与 TeslaMate。
2. 用 Tesla Auth 在本机 Tesla 登录页获得 Access Token 和 Refresh Token，并填入本机 TeslaMate。
3. 看到车辆状态从 `unauthenticated` 变为 `online` / `asleep`，才算授权成功。
4. 保持电脑唤醒并联网，从此记录新行程。
5. 设置常用电价和默认对比油车；飞书 Webhook 为可选配置。

无项目方账号体系、无公共服务器。Tesla Token 和飞书 Webhook 只保存在用户本机。持续记录模式需要本地采集器在线；这项限制必须在向导和视频中明说。

## 默认对比车池

- 日产轩逸
- 大众高尔夫
- 宝马 5 系
- 保时捷 911
- 兰博基尼

进入计算前必须为每个名称锁定具体年款、动力版本、官方油耗、燃油标号、指导价和来源日期。“兰博基尼”必须进一步锁定具体车型。

## 与 Tesla 原生充电统计的差异

- Tesla：聚合充电、预估总费用、泛化燃油车节省。
- 本项目：具体车型、透明公式、可复算假设、五车同屏对比、可分享周/月/年内容。

Tesla App 已经有“燃油费节省金额”，因此不能声称 Tesla 没有省钱数据。差异化问题应改为：

> Tesla 告诉我省了一个数，但它没有告诉我：如果换成轩逸、宝马 5 系或 911，同样里程分别要多花多少钱。

## 计算口径必须分开

- **单次行程电费**：行程耗电 × 有效电价，是估算值。
- **月度实际/估算充电支出**：直接使用 Tesla App 周期总花费或用户账单。
- 两者不强行相加对齐，因为充电损耗、驻车耗电和跨周期剩余电量会造成差异。
- “省多少钱”只指能源费用差，不代表购车、保险、折旧等总持有成本。

## 热力图如何保留

### 1.0：行程日历热力图

- 按日期/行程绘制月历热力图，颜色代表当天行程估算电费。
- 它回答“这个月哪几天跑得最贵”，是可复刻的主视觉。

### 实验版：路线人民币热力图

- 仅分析 TeslaMate 授权并开始运行后的新行程；
- 按路段着色，回答“这趟钱花在哪几段路”；
- 独立成进阶教程，不影响任何人复刻 1.0。

## 传播钩子

主标题不是“我做了一个 Tesla 数据工具”，而是结果：

> 我把一年的特斯拉电费翻出来：同样里程，轩逸要多花多少，911 又要多花多少？

第一屏必须直接展示真实金额差，而不是能耗单位或技术架构。
