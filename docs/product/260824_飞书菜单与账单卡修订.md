# 飞书菜单与账单卡修订

> 决策日期：2026-08-24

## 四个固定入口

1. 最近行程：单次里程、时长、估算耗电和该次 GPS 轨迹。
2. 车辆概览：最新车辆状态，合并本月行程次数、里程和时长。
3. 本周账单：周期汇总和油车对比，不绘制多次路线。
4. 本月账单：周期汇总和油车对比，不绘制多次路线。

充电账单不占菜单入口。用户直接发图即可；飞书将手机端单张图片包装成 `post` 时，Worker 也必须识别其中的 `img_*` 资源。

## 油车对比口径

飞书卡片使用中国用户容易识别的简称；后台独立保留计算版本：

| 卡片名称 | 计算版本 |
|---|---|
| 日产轩逸 | 十五代轩逸 |
| 宝马5系 | BMW 530Li |
| 路虎卫士 | 卫士 110 P400 |
| 保时捷911 | 911 GT3 |
| 兰博基尼超跑 | Aventador S Roadster（经典停产） |

- 十五代轩逸：5.88 L/100km。
- BMW 530Li：6.70 L/100km。
- 卫士 110 P400：11.27 L/100km，上线前仍需完成具体版本映射复核。
- 911 GT3：12.70 L/100km。
- Lamborghini Aventador S Roadster：19.20 L/100km；必须显示“经典停产车型”，只作传播锚点。

### 2026-08-25 油价口径修订

- 产品不推断用户所在地，也不把某个油站成交价当成全国统一价格。
- 统一采用“北京当日参考价”作为车型比较基准：每日联网刷新 92#/95#/98#，结果写入本机缓存。
- 92#/95# 与北京市发展改革委现行最高零售价交叉核对；98# 使用同一北京油价页面的市场挂牌参考值。
- 刷新失败时沿用最近一次成功缓存，并在卡片上改称“最近一次统一参考价”，不得冒充今日价格。
- 卡片只显示斜体免责声明：`油价根据今日统一参考价预估；受地区、油站及优惠影响，结果可能存在偏差。`
- 数据来源与生效日期保存在 `data/processed/reference-fuel-prices.json`，不在卡片底部重复展示。
