# 默认电价与充电批次分摊实施计划

1. 固化改动前基线，隔离动态油价测试数据。
2. 用纯函数测试驱动特殊批次推导、FIFO 消耗、默认价历史与成本汇总。
3. 为本地账本增加默认价历史、一次性 onboarding 状态和并发安全写入。
4. 增加不含位置数据的逐行程能耗时间线查询。
5. 增加默认电价菜单入口、输入表单、严格校验、成功/失败反馈和首次菜单提示。
6. 将单趟、周报和月报成本切换为新的确定性分摊结果。
7. 覆盖账单确认、防重复批次、重启重算、跨周期、缺失数据、上海时间与既有卡片回归。
8. 运行语法检查、完整单元测试、live-safe 测试、diff 检查和敏感信息扫描。
9. 将已验证提交仅合入 M1 本地 `main`，保留运行数据并重启现有 Worker。
10. 验证四个容器、Worker、两个飞书 consumer、MQTT/行程/充电监控和稳定日志；不执行 `git push`。
