# M5 迁移到 M1

## 结论

- GitHub 只备份代码、测试和文档，当前仓库已公开，运行数据与凭证不得提交。
- iCloud Desktop 只传输一次性加密迁移包，不直接同步 Docker volume、`.env`、原始 GPS 或充电账单图片。
- 进程不能同步。M1 需要重新启动 Docker Compose 和 LaunchAgent。
- 采用两阶段切换：先预导入验证；最终切换时停止 M5，再生成最终包并在 M1 恢复。

## 为什么不能直接把运行目录放进 iCloud

Docker 数据卷和 PostgreSQL 数据文件会持续写入。文件级同步可能拿到不同时间点的碎片，不能替代数据库备份。LaunchAgent 和 Docker 进程也只属于当前 Mac，不会随文件同步迁移。

## 迁移内容

加密包包含：

- TeslaMate PostgreSQL 逻辑备份：行程、轨迹、充电会话和车辆状态历史。
- TeslaMate `.env`：数据库密码与加密密钥，仅存在于加密包内。
- 已确认充电账本、飞书账单原图和本地运行状态。
- 最终 `cutover` 包还包含 `tesla-saving-ticket` 飞书 profile；App Secret 只存在于 AES-256 加密包和两台 Mac 的本机安全配置中。

不包含：

- `node_modules`、日志、缓存地图和 Tesla Auth 发布包。
- M5 的运行进程与 Docker volume 原始目录。

## 阶段一：不停车预验证

M5：

```bash
./scripts/migration/export-m5.sh --mode preflight --output "$HOME/Desktop"
```

M1：

```bash
git clone https://github.com/manwithshit/tesla-saving-ticket.git
cd tesla-saving-ticket
npm ci
./scripts/migration/import-m1.sh \
  --bundle "$HOME/Desktop/tesla-saving-ticket-m5-preflight-时间.tar.enc" \
  --replace-target-db \
  --mode preflight
./scripts/migration/verify-m1.sh preflight
```

预验证只启动 M1 的 PostgreSQL、Mosquitto 和 Grafana。TeslaMate 与飞书 Worker 保持停止，避免两台电脑同时采集或重复回复消息。

## 阶段二：最终切换

M5：

```bash
./scripts/migration/export-m5.sh --mode cutover --output "$HOME/Desktop"
```

该命令先停止 M5 的 TeslaMate 与飞书 Worker，再生成最后一个一致性备份。若导出失败，会尝试恢复 M5 服务。

最终导出会先在 M5 本机读取 `tesla-saving-ticket` profile，再把它写入加密包；不会产生明文 iCloud 文件、命令历史或日志。M1 导入时通过 `lark-cli --app-secret-stdin` 写入本机 profile，临时解密目录随后清理。

导入最终包：

```bash
./scripts/migration/import-m1.sh \
  --bundle "$HOME/Desktop/tesla-saving-ticket-m5-cutover-时间.tar.enc" \
  --replace-target-db \
  --mode cutover \
  --source-m5-stopped
./scripts/migration/verify-m1.sh cutover
```

## 回滚

如果 M1 最终验证失败：

```bash
docker compose -f infra/teslamate/compose.yaml down
launchctl bootout "gui/$(id -u)/com.tesla-saving-ticket.worker" 2>/dev/null || true
```

随后在 M5 恢复：

```bash
docker compose -f infra/teslamate/compose.yaml up -d
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/com.tesla-saving-ticket.worker.plist"
```

回滚后不要让 M1 与 M5 同时运行飞书 Worker。
