# 自动链路预验收与地图缓存

## 本次改动

- 上次行程地图：渲染与飞书上传各重试 2 次；成功后按行程写入本地缓存，重复点击不再重新生成和上传。
- 地图失败反馈：已有行程但地图失败时显示“地图生成失败，可重新点击”，不再误报“完成第一段行程后自动出现”。
- 日志：仅记录阶段、耗时、缓存命中和错误类型，不记录行程 ID、坐标或道路。
- 周/月自动推送：错过精确分钟后会在当前自然周或自然月内补发；成功后持久化发送标记，避免重复。
- 账单确认：本地账本写入失败会明确提示；成功反馈遇到临时发送失败会重试。
- 周/月卡片不等待实时油价网络请求；后台更新失败时继续使用本地统一参考价。
